UML Class Architecture Diagnostic Rules

Rule 1: Abstract Subclass Requirement

Every abstract class must be extended by at least one concrete child class.

Rule 2: Interface Realization

Interfaces must be implemented by at least one class in the diagram model.

Rule 3: Interface Operation Completion

Any class implementing an interface must declare all signatures specified by that interface.

Rule 4 & 5: Inheritance Cycle & Single Parent Rule

Circular inheritance is forbidden, and classes should not inherit from multiple parent classes.

Rule 6: Aggregation / Composition Object Reference & Methods

When Class A aggregates Class B (e.g. Student aggregates Department):

  • The aggregate class (Student) must contain an attribute referencing Department.
  • The aggregate class must contain at least 5 operations interacting with Department (e.g., registerDepartment(), showDepartmentDetails(), changeDepartment(), removeDepartment(), updateDepartment()).
